# Переработка

Приложение для телефона: учёт переработки и зарплаты в драмах (֏). Работает на Android и iPhone, ставится на главный экран, работает без интернета. Данные хранятся только на телефоне.

Открыть: https://alenohanyan11-hue.github.io/overtime-app/

## Разработка

```bash
npm install
npm run dev     # локальный сервер
npm test        # тесты
npm run build   # сборка в dist/
```

При каждом изменении ветки `main` GitHub Actions прогоняет тесты, собирает приложение и публикует его на GitHub Pages.
